# Tuneful

Six short music games for beginners, built for the music module of CS 85 (Fall 2026).

**Play it:** https://yidonghe0207.github.io/tuneful/

| Game | What it trains |
| --- | --- |
| Echo Garden | Remembering short melodies |
| Bright or Dark | Hearing major (bright) vs minor (dark) chords |
| Sky Singer | Singing in tune (your pitch steers a dot through a song) |
| Mo the Blob | Matching a single note |
| Note Reader | Reading notes on the treble staff |
| Beat Lab | Clapping rhythms on the beat |

The singing games use your microphone (your browser will ask first). Without a microphone, drag on the game area or use the arrow keys.

Built with HTML, CSS and JavaScript in one file (`index.html`), using the Web Audio API for sound and pitch detection.
